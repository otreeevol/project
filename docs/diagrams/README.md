# UML 图

本目录包含学生信息管理系统的 UML 模型图，每张图同时提供 **PlantUML 源文件（.puml）** 与 **渲染后的图片（.png）**，对应关系如下：

| 图类型 | 源文件 | 图片 | 所属阶段 |
| --- | --- | --- | --- |
| 用例图 | `usecase.puml` | `usecase.png` | 需求分析 |
| 顺序图（新增学生） | `sequence-add-student.puml` | `sequence-add-student.png` | 需求分析 / 详细设计 |
| 顺序图（登录） | `sequence-login.puml` | `sequence-login.png` | 需求分析 / 详细设计 |
| 状态图（学生对象） | `state.puml` | `state.png` | 需求分析 / 详细设计 |
| 包图 | `package.puml` | `package.png` | 总体设计 |
| 构件图 | `component.puml` | `component.png` | 总体设计 |
| 部署图 | `deployment.puml` | `deployment.png` | 总体设计 / 部署 |
| 类图 | `class.puml` | `class.png` | 详细设计 |
| 活动图（新增学生） | `activity-add-student.puml` | `activity-add-student.png` | 详细设计 |

> 在文档（`docs/*.md`）中，这些图以 Mermaid 语法内嵌，可直接在 GitHub 上渲染预览；如需 Word / PDF 提交，请使用本目录的 `.png` 图片。
